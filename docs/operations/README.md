# Operations

Production runbooks will be developed in this directory.

Required runbook topics:

- Pre-survey sensor calibration and site safety
- Incomplete or corrupt upload recovery
- Failed SLAM or registration investigation
- Draft review and two-person publication approval
- Release rollback and consumer compatibility
- False change-alert investigation
- Raw camera-data retention and access requests
- Object-store and database backup and restore

Operational procedures must never modify a published artifact in place.
