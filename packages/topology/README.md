# Topology

Contains rules for generating and editing a driving graph from geometry and
operator knowledge.

## Responsibilities

- Suggest edges from corridor centerlines.
- Identify intersection, station, and holding-point candidates.
- Model one-way, speed, width, clearance, and robot-class rules.
- Link assets and zones to nodes and edges.
- Analyze connectivity and reachability.

Automated output is a suggestion; operator approval and validation are required
before publication.
